# MHAQ

## General instructions

* Always communicate with the user in Russian.
* Before making significant changes, briefly explain what you are going to do.

## Python environment

* Always use the project virtual environment (`.venv`) for Python-related tasks.
* Do not use system Python or global `pip`.
* Before running Python commands, activate `.venv` or use `.venv/bin/python` / `.venv/bin/pip` directly.
* Install packages via `python -m pip`, not plain global `pip`.
